## 📌 Descrição

Este repositório contém a implementação de um programa em Java de uma calculadora básica, desenvolvido utilizando conceitos de Programação Orientada a Objetos (POO).

O programa solicita ao usuário dois números, realiza as quatro operações matemáticas básicas (soma, subtração, multiplicação e divisão) por meio de uma classe chamada Calculadora, e exibe os resultados no console.

A entrada de dados é feita através da classe Scanner, enquanto a lógica das operações matemáticas é organizada em métodos específicos dentro da classe de cálculo.

## 📋 Estrutura do Código

O programa foi organizado seguindo os seguintes critérios:

A entrada de dados é realizada através da classe Scanner, permitindo que o usuário informe dois números.

A classe Calculadora é responsável por executar as operações matemáticas.

Cada operação matemática é implementada em um método específico (somar, subtrair, multiplicar e dividir).

O método main realiza:

a leitura dos números digitados pelo usuário,

a chamada dos métodos da classe Calculadora,

e a exibição dos resultados no console.

Após a execução das operações, o Scanner é fechado utilizando sc.close().

Essa estrutura separa entrada de dados, lógica de cálculo e execução, facilitando a organização e manutenção do código.

---

## ▶️ Funcionamento do Programa

O programa solicita que o usuário digite o primeiro número.

Em seguida, solicita o segundo número.

Os valores informados são enviados para a classe Calculadora.

A classe executa as seguintes operações:

Soma

Subtração

Multiplicação

Divisão

Os resultados de cada operação são exibidos no console.
